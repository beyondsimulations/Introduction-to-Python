The investor is finally in the shop, clipboard out, asking to see real numbers
by the end of the week. Tobi proposes going "on vibes"; her expression does not change.
So this week you stop hand-rolling arithmetic and reach for Python's **standard
library**: you'll `import math` and `statistics` for professional-grade counts
and averages, then use `random` to *rehearse* next week's demand. You'll also
learn why a projection you can run twice, and get the same answer, is one an
investor can trust. It's also the first notebook where **AI tools are
allowed**; the checks still only go green on code that actually runs.
